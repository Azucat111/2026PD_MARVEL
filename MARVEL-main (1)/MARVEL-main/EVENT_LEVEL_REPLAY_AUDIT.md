# 事件级回放和归档准入

版本 `joint-public-event-replay-v1` 从真实原子提交对齐到下一原子决策。每条记录保存 `state` 和 `next_state`，二者各含稳定候选 ID、公开快照 SHA、实际图特征及观测时钟。动作是当时合法集合的行号，稳定 ID 由当前状态解释。另记录 `reward`、`dt`、`done`、`truncated`、`scenario_id`、`seed`、`policy_id`、`group`、已记录的行为概率及分布。空图无动作，该段物理时间归入跨边界的真实时长。

## 归档准入

- 上轮 P2-O 研究逐事件记录冻结 actor 分数、掩码、原子回执和物理轨迹。Phase 3.5 的冻结 J0 归档从原公共快照重建图并校验原 mask，旧日志缺少的行为概率标为缺失。
- Phase 3 的四条主训练轨迹有真实时间、动作、公开快照、掩码、行为 log-prob 和 H300 物理轨迹。导入重放图、验证 SHA、恢复原 logits 相对值和实际提交。旧 log-prob 反归一化仅修正浮点舍入。Phase 3 短段和仅有控制摘要的评估臂排除。
- 同一场景、实际提交和全物理评分轨迹的重复回合只保留一个。合法反事实分支按同一 case/seed 分组，回放先均匀抽 seed 组再抽事件。不足 H300 的末状态标为截断，训练排除这类回合。完整失败窗口按官方 H300 计为 300 秒。
- 历史记录缺少完整环境随机状态。新分支使用同场景随机种子从头重跑，行为抽样使用独立 RNG，事后核对共享前缀、候选及快照。在线网络仅输入公开观测。

## 物理计奖

令 `c*` 为物理轨迹首次满足搜索、通信和连续 3 秒条件的时间，尚无候选完成时按当前物理秒累积。事件奖励是累积成本的负差，除以 30 秒用于数值缩放。先满足完成窗口后发生全窗口失败，末端补上到 300 秒的剩余成本。成功成本与 300 秒失败成本均与官方指标一致。首个动作前的物理成本单独记录，是本次 episode 给定初态的常数。终点仍为 H300，通信首次稳定后的实际动作仍可能影响窗口最终安全。末记录无下一合法图，终止靶不 bootstrap。

采集、数据分组、缺字段及覆盖计数由 `scripts/build_mature_rl_replay.py` 写入每个 replay 的 JSON 审计和模型训练日志。

## 归档实际结果

去重后 15/22 条完整轨迹，9 个独立种子组、四域 78 个实际可训练动作。33 次混合事件中 Search 28、Relay 5。30 次 Search-only 和 15 次 Relay-only 分别实际执行其唯一角色。四域计数为 38、23、9、8。39 条具有直接记录或经可审计旧 log-prob 恢复的概率，其余缺失保持缺失。
