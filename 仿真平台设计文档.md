## 1. 任务场景设计

### 1.1 场景名称：城市应急搜救与信息中继

#### 1.1.1 场景背景

城市某区域发生突发事件（地震/洪水），30-60架无人机集群需要执行多任务协同：

1. **区域探索** - 快速绘制受灾区域地图（继承MARVEL探索能力）
2. **目标搜寻** - 在废墟中定位幸存者位置（热源/信号源）
3. **通信中继** - 部分无人机作为通信节点维持集群连接
4. **禁飞区规避** - 动态出现的二次灾害区域（火灾扩散、建筑倒塌）

#### 1.1.2 地图设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 地图尺寸 | 150m × 150m | 城市街区规模 |
| 分辨率 | 1.0 m/pixel | 与MARVEL保持一致 |
| 静态障碍 | 建筑物、废墟、道路 | 从地图文件加载 |
| 动态障碍 | 2-3个火灾扩散区 | 圆形扩张，速率0.1-0.15 m/step |
| 烟雾区 | 1-2个 | 随机漂移，降低传感器效率50% |

#### 1.1.3 无人机配置

**基础配置（30架）**：

| 类型 | 数量 | FoV | 传感范围 | 速度 | 特殊能力 |
|------|------|-----|---------|------|---------|
| 探索型 | 20 | 120° | 10m | 2.0 m/s | 标准探索 |
| 中继型 | 5 | 90° | 12m | 1.5 m/s | 通信范围25m |
| 搜救型 | 5 | 90° | 8m | 2.5 m/s | 快速响应 |

**扩展配置（60架）**：按比例翻倍

#### 1.1.4 任务定义

##### Task 1: 全区域快速探索（EXPLORATION）

- **优先级**: High (3)
- **目标**: 在300步内覆盖80%未知区域
- **奖励设计**:
  - +1.0 每消除10个frontier
  - +10.0 完成80%覆盖
  - -0.1 每步时间惩罚（鼓励快速）
- **分配**: 所有探索型无人机
- **激活条件**: 初始即激活

##### Task 2: 热点目标搜寻（TARGET_SEARCH）

- **优先级**: Critical (5)
- **目标**: 定位3-5个预设的"幸存者位置"（热源点）
- **触发条件**: 探索率达到30%后激活（约step 100）
- **目标位置**: 
  - Target 1: [30, 30]
  - Target 2: [80, 120]
  - Target 3: [140, 60]
  - Target 4: [50, 100]
  - Target 5: [110, 110]
- **奖励设计**:
  - +20.0 每发现一个目标（进入5m范围）
  - +5.0 接近未发现目标（距离reward shaping）
  - -0.5 已发现目标附近重复巡航（避免浪费）
- **分配**: 搜救型 + 部分探索型（动态切换）

##### Task 3: 通信链路维持（RELAY）

- **优先级**: Medium (2)
- **目标**: 保持集群连通性 > 90%
- **约束**:
  - 通信范围: 20m
  - 单跳延迟: 50ms
  - 允许最大2跳到达基站
- **奖励设计**:
  - +0.5 每步保持全连通
  - -5.0 出现孤岛节点（某无人机失联）
- **分配**: 中继型（固定） + 边缘探索型（兼职）

##### Task 4: 动态禁飞区规避（SAFETY）

- **优先级**: Critical (5)
- **持续任务**: 所有无人机必须实时响应
- **触发**: 火灾扩散、建筑倒塌事件
- **奖励设计**:
  - -50.0 进入禁飞区（强惩罚）
  - -10.0 距离禁飞区 < 5m（危险接近）
  - +2.0 成功从禁飞区脱离

#### 1.1.5 时间线与事件

```
Step 0-50:    初始探索阶段
              - 所有探索型执行Task 1
              - 中继型分散到关键位置
              
Step 50:      事件1 - 火灾A出现
              - 位置: [80, 80]
              - 初始半径: 5m
              - 扩张速率: 0.1 m/step
              - 附近3架无人机需要重规划
              
Step 100:     探索率达到30%，Task 2激活
              - 5架搜救型切换到目标搜寻
              - 2架探索型也参与（任务切换）
              
Step 150:     事件2 - 火灾B出现
              - 位置: [120, 50]
              - 初始半径: 3m
              - 扩张速率: 0.15 m/step
              - 通信拓扑受影响，需要调整中继位置
              
Step 200:     第1个目标被发现
              - 触发"重点勘察"子任务（需要2架协同确认）
              
Step 250:     事件3 - 烟雾区漂移
              - 降低该区域传感器效率到50%
              
Step 300:     任务截止
```

#### 1.1.6 评测指标

| 指标 | 目标值 | 权重 | 说明 |
|------|--------|------|------|
| 探索覆盖率 | ≥80% | 25% | 已探索自由栅格/总自由栅格 |
| 目标发现数 | 3/5 | 30% | 发现的幸存者数量 |
| 任务完成时间 | ≤300步 | 15% | Makespan（最后一个任务完成的时间） |
| 通信连通性 | ≥90% | 10% | 保持全连通的步数比例 |
| 碰撞/违规次数 | 0 | 15% | 静态碰撞+动态禁飞区违规 |
| 平均航程 | <500m | 5% | 能耗指标 |

**效率基准**: 与传统规则调度（固定探索→串行搜寻→无动态重规划）对比，目标提升15%

#### 1.1.7 技术挑战对应

| 揭榜需求 | 场景体现 |
|---------|---------|
| 多任务切换 | 探索→搜寻的动态切换，中继任务并行 |
| 动态障碍 | 火灾扩散、烟雾漂移 |
| 30-60架规模 | 两档配置，测试规模化协同 |
| 通信约束 | 显式建模通信范围和延迟 |
| 在线重规划 | 禁飞区出现触发避障和路径重算 |
| 协同优化 | 目标确认需要多机协同、中继位置优化 |

## 3. 核心组件详细设计

### 3.1 动力学模型（Dynamics Models）

#### 3.1.1 设计目标

- 支持从简单到复杂的渐进式开发
- Level 0用于快速训练，Level 1用于真实验证
- 保持与MARVEL原代码的兼容性

#### 3.1.2 Level 0: KinematicSimple（当前MARVEL模型）

**特性**：
- 恒定速度（VELOCITY = 1.0 m/s）
- 只考虑yaw rate约束（YAW_RATE = 35°/s）
- 位置线性插值（NUM_SIM_STEPS = 6）
- 无加速度、无转弯半径约束

**公式**：
```
achievable_heading = compute_allowable_heading(...)  # 原motion_model.py
position[t+1] = position[t] + Δt * velocity * direction
heading[t+1] = heading[t] + Δθ (受yaw_rate约束)
```

**用途**：
- 初期训练（快速迭代）
- 策略网络预训练
- 消融实验对比基线

**实现位置**: `utils/dynamics_models.py::KinematicSimple`

#### 3.1.3 Level 1: KinematicWithAccel（新增真实约束）

**特性**：
- 速度范围约束：v ∈ [0.3, 2.5] m/s
- 最大加速度：a_max = 1.2 m/s²
- 最大角速度：ω_max = 45°/s
- 最大角加速度：α_max = 30°/s²
- 最小转弯半径：r_min = 0.8 m

**公式**：
```python
# 1. 速度约束
v[t+1] = clip(v_desired, v[t] - a_max*dt, v[t] + a_max*dt)
v[t+1] = clip(v[t+1], v_min, v_max)

# 2. 角速度约束
ω[t+1] = clip(ω_desired, ω[t] - α_max*dt, ω[t] + α_max*dt)
ω[t+1] = clip(ω[t+1], -ω_max, ω_max)

# 3. 转弯半径约束
if |ω[t+1]| > 0:
    r = v[t+1] / |ω[t+1]|
    if r < r_min:
        v[t+1] = r_min * |ω[t+1]|  # 降速满足约束

# 4. 状态更新
θ[t+1] = θ[t] + ω[t+1] * dt
x[t+1] = x[t] + v[t+1] * cos(θ[t+1]) * dt
y[t+1] = y[t] + v[t+1] * sin(θ[t+1]) * dt
```

**关键改进**：
- ✅ 加速度约束（不能瞬间加速到最大速度）
- ✅ 最小转弯半径（高速时不能急转弯）
- ✅ 角加速度约束（不能瞬间改变转向）
- ✅ 返回可行性标志（用于奖励设计和安全屏蔽）

**输出**：
```python
{
    'new_state': {
        'position': np.array([x, y]),
        'velocity': float,
        'heading': float,
        'angular_velocity': float
    },
    'feasibility': {
        'speed_saturated': bool,      # 加速度饱和
        'turn_saturated': bool,        # 转向饱和
        'min_radius_violated': bool    # 违反最小转弯半径
    }
}
```

**用途**：
- 最终评测验证
- sim-to-real准备
- 与Level 0的对比实验

**实现位置**: `utils/dynamics_models.py::KinematicWithAccel`

#### 3.2.1 IdealSensor（当前MARVEL）

**特性**：

### 3.3 通信模型（Communication Model）

#### 3.3.1 设计目标

- 显式建模通信范围、延迟、丢包
- 支持拓扑计算（用于中继任务）
- 检查集群连通性

#### 3.3.2 核心功能

**1. 通信范围限制**：
```python
def get_topology(self, robot_positions: List[np.ndarray]) -> np.ndarray:
    """
    返回通信拓扑邻接矩阵 A[i,j] = 1 if dist(i,j) < comm_range
    """
    n = len(robot_positions)
    adjacency = np.zeros((n, n))
    
    for i in range(n):
        for j in range(i+1, n):
            dist = np.linalg.norm(robot_positions[i] - robot_positions[j])
            if dist <= self.comm_range:
                adjacency[i, j] = adjacency[j, i] = 1
    
    return adjacency
```

**2. 延迟模拟**：
```python
def broadcast(self, sender_id, sender_pos, message, timestamp):
    """
    模拟消息广播，考虑延迟和丢包
    """
    receivers = self._get_neighbors_in_range(sender_id, sender_pos)
    
    for receiver_id, receiver_pos in receivers:
        distance = np.linalg.norm(sender_pos - receiver_pos)
        
        # 延迟 = 传播延迟 + 处理延迟
        propagation_delay = distance / 3e8 * 1000  # 光速传播 (ms)
        processing_delay = np.random.exponential(self.latency_base)
        total_delay = propagation_delay + processing_delay
        
        # 丢包判断
        if np.random.rand() < self.packet_loss:
            continue
        
        # 加入消息队列
        delivery_time = timestamp + total_delay / 1000
        self.message_queue.append({
            'from': sender_id,
            'to': receiver_id,
            'message': message,
            'delivery_time': delivery_time
        })
```

**3. 连通性检查**：
```python
def check_connectivity(self, adjacency: np.ndarray) -> Tuple[bool, int]:
    """
    使用图连通分量算法检查集群是否全连通
    """
    from scipy.sparse.csgraph import connected_components
    n_components, labels = connected_components(adjacency)
    return n_components == 1, n_components
```

### 3.4 障碍物管理（Obstacle Manager）

#### 3.4.1 静态障碍

- 从地图文件加载（继承MARVEL的`import_ground_truth`）
- 栅格表示：FREE=255, OCCUPIED=1, UNKNOWN=127

#### 3.4.2 动态障碍

**ExpandingCircleObstacle（火灾扩散）**：

```python
class ExpandingCircleObstacle:
```

```python
def check_collision(self, robot_pos: np.ndarray, robot_radius: float = 0.2) -> Tuple[bool, Optional[str]]:
    """
```

#### 3.5.2 任务管理器

```python
class TaskManager:
    def __init__(self, task_configs: List[dict]):
        self.tasks = [self._create_task(cfg) for cfg in task_configs]
        self.current_step = 0
    
    def update(self, current_step, robot_states, observations) -> List[dict]:
        """
        更新任务状态，返回事件列表
        
        返回：[{'type': 'task_activated', 'task_id': 'T2', ...}, ...]
        """
        self.current_step = current_step
        events = []
        
        for task in self.tasks:
            # 检查激活条件
            if task.status == TaskStatus.PENDING:
                if self._should_activate(task, observations):
                    task.status = TaskStatus.ACTIVE
                    task.start_step = current_step
                    events.append({
                        'type': 'task_activated',
                        'task_id': task.task_id,
                        'step': current_step
                    })
            
            # 更新进度
            if task.status == TaskStatus.ACTIVE:
                progress_event = self._update_progress(task, robot_states, observations)
                if progress_event:
                    events.append(progress_event)
                
                # 检查完成条件
                if self._is_completed(task):
                    task.status = TaskStatus.COMPLETED
                    task.end_step = current_step
                    events.append({
                        'type': 'task_completed',
                        'task_id': task.task_id,
                        'step': current_step,
                        'duration': current_step - task.start_step
                    })
        
        return events
    
    def _should_activate(self, task, observations) -> bool:
        """检查任务激活条件"""
        # 1. 基于step的激活
        if task.activation_step is not None:
            if self.current_step >= task.activation_step:
                return True
        
        # 2. 基于条件的激活（例如"exploration_rate >= 0.3"）
        if task.activation_condition:
            # 简单实现：解析字符串条件
            # 实际可以用更复杂的条件DSL
            if "exploration_rate" in task.activation_condition:
                # 从observations中计算exploration_rate
                exploration_rate = self._compute_exploration_rate(observations)
                threshold = float(task.activation_condition.split(">=")[1])
                return exploration_rate >= threshold
        
        return False
    
    def _update_progress(self, task, robot_states, observations) -> Optional[dict]:
        """更新任务进度"""
        if task.task_type == TaskType.TARGET_SEARCH:
            # 检查是否有新目标被发现
            targets = task.params['targets']
            assigned_robots = [r for r in robot_states if r.robot_id in task.assigned_robot_ids]
            
            for target in targets:
                if not target.get('found', False):
                    for robot in assigned_robots:
                        dist = np.linalg.norm(robot.position - np.array([target['x'], target['y']]))
                        if dist < target.get('radius', 5.0):
                            target['found'] = True
                            target['found_by'] = robot.robot_id
                            target['found_step'] = self.current_step
                            return {
                                'type': 'target_found',
                                'task_id': task.task_id,
                                'target': target,
                                'robot_id': robot.robot_id,
                                'step': self.current_step
                            }
        
        return None
```

```python
class Evaluator:
    def __init__(self, scenario_config, log_dir):
        self.config = scenario_config['evaluation']
        self.log_dir = log_dir
        self.metrics_history = []
    
    def record_step(self, step, observations, info):
        """记录每步的指标"""
        metrics = {
            'step': step,
            'exploration_rate': self._compute_exploration_rate(observations),
            'targets_found': self._count_targets_found(info['task_events']),
            'connectivity': self._compute_connectivity(info['comm_topology']),
            'collisions': len(info['collisions']),
            'total_distance': self._compute_total_distance(observations)
        }
        self.metrics_history.append(metrics)
    
    def generate_report(self) -> dict:
        """生成最终评测报告"""
        final_metrics = {}
        
        for metric_cfg in self.config['metrics']:
            name = metric_cfg['name']
            weight = metric_cfg['weight']
            target = metric_cfg.get('target')
            
            # 计算指标值
            if name == 'exploration_rate':
                value = self.metrics_history[-1]['exploration_rate']
                score = value / target if target else value
            elif name == 'targets_found':
                value = self.metrics_history[-1]['targets_found']
                score = value * metric_cfg.get('score_per_target', 1)
            elif name == 'makespan':
                value = len(self.metrics_history)
                score = max(0, 1 - (value - target) / target)
            # ... 其他指标
            
            final_metrics[name] = {
                'value': value,
                'target': target,
                'score': score,
                'weight': weight,
                'weighted_score': score * weight
            }
        
        total_score = sum(m['weighted_score'] for m in final_metrics.values())
        
        report = {
            'metrics': final_metrics,
            'total_score': total_score,
            'timestamp': datetime.now().isoformat()
        }
        
        # 保存报告
        self._save_json(report)
        self._save_markdown(report)
        
        return report
```

```python
# utils/scenario_config.py
import yaml
from pathlib import Path
from typing import Dict

def load_and_validate_scenario(scenario_file: Path) -> Dict:
    """
    加载并验证场景配置
    
    验证内容：
    1. 必需字段存在性
    2. 数值范围合法性
    3. 引用文件存在性
    4. robot ID不重叠
    """
    with open(scenario_file, 'r', encoding='utf-8') as f:
        config = yaml.safe_load(f)
    
    # 验证必需字段
    required_fields = ['scenario', 'environment', 'robots', 'tasks']
    for field in required_fields:
        if field not in config:
            raise ValueError(f"Missing required field: {field}")
    
    # 验证robot ID不重叠
    id_ranges = [r['id_range'] for r in config['robots']]
    for i, range1 in enumerate(id_ranges):
        for j, range2 in enumerate(id_ranges[i+1:], i+1):
            if _ranges_overlap(range1, range2):
                raise ValueError(f"Robot ID ranges overlap: {range1} and {range2}")
    
    # 验证引用文件存在
    for module in ['dynamics', 'sensor', 'communication']:
        if module in config:
            config_file = Path(config[module]['config_file'])
            if not config_file.exists():
                raise FileNotFoundError(f"{module} config not found: {config_file}")
    
    # 加载子配置
    for module in ['dynamics', 'sensor', 'communication']:
        if module in config:
            with open(config[module]['config_file'], 'r') as f:
                config[module]['params'] = yaml.safe_load(f)
    
    return config

def _ranges_overlap(range1, range2):
    """检查两个ID范围是否重叠"""
    return not (range1[1] < range2[0] or range2[1] < range1[0])
```

```python
# utils/simulation_runtime.py
"""
统一仿真运行时，封装物理模拟和传感器。
借鉴卓翼杯的模块化设计：Runtime独立于策略和评测。
"""
import numpy as np
from typing import List, Dict, Tuple, Optional
from dataclasses import dataclass
import time

from .dynamics_models import create_dynamics_model
from .sensor_models import create_sensor_model
from .communication_model import CommunicationModel
from .obstacle_manager import ObstacleManager
from .task_manager import TaskManager


@dataclass
class RobotState:
    """机器人状态（类似卓翼杯的odom）"""
    robot_id: int
    position: np.ndarray  # (x, y)
    velocity: float
    heading: float  # degrees
    angular_velocity: float  # deg/s
    
    # 扩展状态（用于Level 1动力学）
    acceleration: Optional[float] = None
    vx: Optional[float] = None
    vy: Optional[float] = None


class SimulationRuntime:
    """
    仿真运行时核心类。
    
    类似卓翼杯的competition_runtime，负责：
    1. 物理模拟（动力学、碰撞）
    2. 传感器模拟
    3. 通信拓扑
    4. 动态障碍更新
    5. 任务状态管理
    
    **不负责**：策略决策、奖励计算、评测（由外部模块处理）
    """
    
    def __init__(self, scenario_config: Dict):
        self.config = scenario_config
        self.current_step = 0
        self.dt = scenario_config['duration']['step_dt']
        
        # 加载子模块
        self.dynamics = create_dynamics_model(
            scenario_config['dynamics']['config_file']
        )
        self.sensor = create_sensor_model(
            scenario_config['sensor']['config_file']
        )
        self.comm = CommunicationModel(
            scenario_config['communication']
        )
        self.obstacles = ObstacleManager(
            scenario_config['environment'],
            scenario_config.get('dynamic_obstacles', [])
        )
        self.tasks = TaskManager(scenario_config['tasks'])
        
        # 机器人状态
        self.robots: List[RobotState] = []
        self.robot_types: Dict[int, str] = {}
        
        # 事件日志（用于归档）
        self.events = []
    
    def reset(self) -> Dict:
        """
        重置仿真环境。
        
        返回：初始观测字典（类似Gymnasium）
        """
        self.current_step = 0
        self.events = []
        
        # 初始化机器人
        self.robots = []
        self.robot_types = {}
        
        for robot_group in self.config['robots']:
            id_start, id_end = robot_group['id_range']
            robot_type = robot_group['type']
            cfg = robot_group['config']
            
            # 生成初始位置（借鉴MARVEL的random_start_list）
            positions = self._generate_initial_positions(
                id_end - id_start + 1,
                cfg.get('initial_positions', 'random_safe')
            )
            
            for i, robot_id in enumerate(range(id_start, id_end + 1)):
                state = RobotState(
                    robot_id=robot_id,
                    position=positions[i],
                    velocity=0.0,
                    heading=np.random.uniform(0, 360),
                    angular_velocity=0.0
                )
                self.robots.append(state)
                self.robot_types[robot_id] = robot_type
        
        # 重置子模块
        self.obstacles.reset()
        self.tasks.reset()
        
        # 记录事件
        self._log_event("simulation_reset", {
            "num_robots": len(self.robots),
            "seed": self.config.get('random_seed')
        })
        
        return self._get_observations()
    
    def step(self, actions: List[Tuple[np.ndarray, float]]) -> Tuple[Dict, Dict]:
        """
        执行一步仿真。
        
        参数：
            actions: [(target_position, target_heading), ...]
        
        返回：
            observations: 观测字典
            info: 仿真信息（碰撞、通信拓扑、任务事件）
        """
        info = {
            'collisions': [],
            'comm_topology': None,
            'task_events': [],
            'feasibility': []
        }
        
        # 1. 更新动态障碍
        self.obstacles.step(self.current_step, self.dt)
        
        # 2. 执行动力学仿真
        for robot, (target_pos, target_heading) in zip(self.robots, actions):
            # 调用动力学模型
            new_state, feasibility = self.dynamics.step(
                current_position=robot.position,
                final_position=target_pos,
                theta_current=robot.heading,
                theta_desired=target_heading,
                v_current=robot.velocity,
                dt=self.dt
            )
            
            info['feasibility'].append({
                'robot_id': robot.robot_id,
                **feasibility
            })
            
            # 碰撞检测
            collision, collision_type = self.obstacles.check_collision(
                new_state['position'],
                radius=0.2  # 机器人半径
            )
            
            if collision:
                info['collisions'].append({
                    'robot_id': robot.robot_id,
                    'type': collision_type,
                    'position': new_state['position'].tolist(),
                    'step': self.current_step
                })
                self._log_event("collision", info['collisions'][-1])
                # 碰撞时保持原位置（或实现碰撞响应）
                continue
            
            # 更新状态
            robot.position = new_state['position']
            robot.velocity = new_state['velocity']
            robot.heading = new_state['heading']
            robot.angular_velocity = new_state.get('angular_velocity', 0.0)
        
        # 3. 传感器观测
        observations = self._get_observations()
        
        # 4. 通信拓扑
        robot_positions = [r.position for r in self.robots]
        comm_topology = self.comm.get_topology(robot_positions)
        info['comm_topology'] = comm_topology
        
        # 检查连通性
        is_connected, n_components = self.comm.check_connectivity(comm_topology)
        if not is_connected:
            self._log_event("disconnection", {
                'step': self.current_step,
                'components': n_components
            })
        
        # 5. 任务状态更新
        task_events = self.tasks.update(
            current_step=self.current_step,
            robot_states=self.robots,
            observations=observations
        )
        info['task_events'] = task_events
        
        for event in task_events:
            self._log_event("task_event", event)
        
        self.current_step += 1
        
        return observations, info
    
    def _get_observations(self) -> Dict:
        """
        生成观测（类似MARVEL的get_observation，但分离清晰）。
        
        返回格式兼容MARVEL Agent输入。
        """
        observations = {}
        
        # 获取当前障碍物栅格（包括动态障碍）
        occupancy_grid = self.obstacles.get_occupancy_grid()
        
        for robot in self.robots:
            # 调用传感器模型
            obs = self.sensor.sense(
                robot_state=robot,
                occupancy_grid=occupancy_grid,
                all_robot_positions=[r.position for r in self.robots]
            )
            observations[robot.robot_id] = obs
        
        return observations
    
    def _generate_initial_positions(self, count: int, mode: str) -> List[np.ndarray]:
        """
        生成初始位置（借鉴MARVEL的random_start_list）
        
        参数：
            count: 机器人数量
            mode: "random_safe" | "grid" | [[x1,y1], [x2,y2], ...]
        """
        if isinstance(mode, list):
            # 显式指定位置
            return [np.array(pos) for pos in mode]
        
        if mode == "random_safe":
            # 随机生成不碰撞的位置
            positions = []
            occupancy_grid = self.obstacles.get_occupancy_grid()
            map_height, map_width = occupancy_grid.shape
            
            attempts = 0
            max_attempts = count * 100
            
            while len(positions) < count and attempts < max_attempts:
                x = np.random.uniform(5, map_width - 5)
                y = np.random.uniform(5, map_height - 5)
                pos = np.array([x, y])
                
                # 检查是否与障碍碰撞
                collision, _ = self.obstacles.check_collision(pos, radius=0.5)
                if not collision:
                    # 检查是否与已有机器人太近
                    too_close = any(
                        np.linalg.norm(pos - existing) < 2.0
                        for existing in positions
                    )
                    if not too_close:
                        positions.append(pos)
                
                attempts += 1
            
            if len(positions) < count:
                raise RuntimeError(
                    f"Failed to generate {count} safe positions after {max_attempts} attempts"
                )
            
            return positions
        
        elif mode == "grid":
            # 网格排列
            grid_size = int(np.ceil(np.sqrt(count)))
            spacing = 5.0
            positions = []
            
            for i in range(count):
                row = i // grid_size
                col = i % grid_size
                x = 10 + col * spacing
                y = 10 + row * spacing
                positions.append(np.array([x, y]))
            
            return positions
        
        else:
            raise ValueError(f"Unknown initial position mode: {mode}")
    
    def _log_event(self, event_type: str, data: Dict):
        """记录事件（用于后续分析）"""
        self.events.append({
            'step': self.current_step,
            'timestamp': time.time(),
            'type': event_type,
            'data': data
        })
    
    def get_event_log(self) -> List[Dict]:
        """返回事件日志（用于归档）"""
        return self.events
    
    def to_marvel_format(self, observations: Dict) -> Dict:
        """
        将仿真输出转换为MARVEL Agent期望的格式。
        保持向后兼容。
        """
```
